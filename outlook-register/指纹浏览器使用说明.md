# 运行指纹浏览器版本

## 步骤 1: 启动指纹浏览器

打开命令行，运行：

```cmd
"C:\Users\meng\AppData\Local\Chromium\Application\chrome.exe" --fingerprint=1000 --user-data-dir=D:\profiles\outlook_reg --remote-debugging-port=9222
```

## 步骤 2: 运行注册脚本

保持浏览器窗口打开，然后运行：

```cmd
run.bat
```

脚本会自动通过 CDP 连接到已运行的指纹浏览器。

## 说明

- `--fingerprint=1000`: 固定指纹种子（每次运行一致）
- `--user-data-dir=D:\profiles\outlook_reg`: 浏览器数据目录（Cookie/缓存等）
- `--remote-debugging-port=9222`: CDP 调试端口（供脚本连接）
