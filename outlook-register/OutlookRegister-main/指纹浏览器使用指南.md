# OutlookRegister 指纹浏览器使用指南

## 快速开始

### 第一步：启动指纹浏览器
双击运行 `start_fingerprint.bat`，浏览器窗口会打开并保持运行。

### 第二步：运行注册脚本
保持浏览器窗口打开，双击运行 `run.bat` 执行注册任务。

## 注意事项

1. **必须先启动指纹浏览器**，再运行 `run.bat`
2. 指纹浏览器窗口不能关闭，否则注册会失败
3. 如需更换指纹种子，修改 `start_fingerprint.bat` 中的 `FINGERPRINT` 参数

## 配置说明

### 指纹浏览器启动参数
- `--fingerprint=1000` - 指纹种子，可更改为任意数字
- `--user-data-dir=D:\profiles\outlook_reg` - 浏览器数据目录
- `--proxy-server=http://127.0.0.1:7897` - 代理服务器

### 项目配置 (config.json)
```json
{
    "choose_browser": "playwright",
    "proxy": "http://127.0.0.1:7897",
    "concurrent_flows": 1,
    "max_tasks": 1,
    "playwright": {
        "browser_path": "C:\\Users\\meng\\AppData\\Local\\Chromium\\Application\\chrome.exe",
        "browser_args": [
            "--fingerprint=1000",
            "--user-data-dir=D:\\profiles\\outlook_reg",
            "--lang=zh-CN"
        ]
    }
}
```

## 常见问题

**Q: 运行 run.bat 报错 "启动浏览器失败"**
A: 请确认指纹浏览器已启动，检查 `start_fingerprint.bat` 是否正常运行。

**Q: 如何更换指纹种子？**
A: 修改 `start_fingerprint.bat` 中的 `FINGERPRINT` 值，同时修改 `config.json` 中的对应参数。

**Q: 可以同时运行多个注册任务吗？**
A: 可以修改 `config.json` 中的 `concurrent_flows` 参数，但建议单个指纹浏览器实例对应单个任务。
